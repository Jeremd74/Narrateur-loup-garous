# UX

## Navigation
- Ecrans : Accueil, Joueurs, Roles, Attribution, Partie (nuit/jour),
  Historique, Fiche role.
- Menu burger : options de partie (appeler les morts par ruse, ordre du
  reveil : morts / infos / roles agissants), historique, quitter.
- Options d'ordre fixees au debut de partie.

## Joueurs
- Liste ordonnee (saisie rapide, carnet de joueurs).
- Placement : liste ordonnee ou cercle visuel (glisser-deposer), bascule
  possible.
- Min 8, max 28.

## Roles
- Compteur par role, total verifie = nombre de joueurs.
- Tirage aleatoire (le narrateur voit le resultat puis distribue les
  cartes physiques) ou attribution manuelle par joueur.
- Voleur : rappel d'ajouter 2 cartes au centre.

## Partie
- Bandeau fixe : nuit/jour N, joueurs vivants, Maire, couple.
- Nuit : l'ecran affiche le role a appeler, une consigne courte, la liste
  des cibles vivantes (gros boutons), un bouton "Passer" quand pertinent.
- Etat des pouvoirs visible (potions de la sorciere, infection utilisee,
  etc.).
- Reveil : suit l'ordre choisi (morts, infos, roles agissants).
- Vote : selection du joueur elimine, "vote blanc", "egalite".
- Cascade : chasseur, amoureux, succession du Maire proposes pas a pas.
- Undo toujours visible.

## Mode "montrer le role"
- Plein ecran : photo de la carte + nom.
- Accessible uniquement quand le moteur autorise (jour, ou tour d'un role
  qui voit une carte).
- Bouton "+" : regles du role.
- Pas d'information sur les autres joueurs.

## Adaptatif
- Portrait uniquement sur smartphone ; portrait et paysage sur tablette.
- Theme suit prefers-color-scheme.
- Cibles >= 48px, usage a une main (actions principales en bas).
